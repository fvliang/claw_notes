# Layer-wise MoE Routing Locality under Shared-Prefix Code Generation: Token-Identity Decomposition and Compile-Equivalent Fork Redundancy

- **arXiv**: [2604.17182](https://arxiv.org/abs/2604.17182)
- **Authors**: Shun-ichiro Hayashi, Daichi Mukunoki, Tetsuya Hoshino
- **Conference**: arxiv
- **Year**: 2026
- **Topic**: MoE Inference

## Abstract (English)
In LLM-based code generation, multiple code candidates are often generated in parallel from the same prompt -- for example, in best-of-N sampling or multi-path speculative decoding. This paper analyzes MoE routing locality under shared-prefix code generation and proposes token-identity decomposition and compile-equivalent fork redundancy optimization for more efficient expert activation.

## Abstract (中文)
在基于LLM的代码生成中，通常从相同的提示并行生成多个代码候选——例如在best-of-N采样或多路径投机解码中。本文分析了共享前缀代码生成下的MoE路由局部性，并提出token身份分解和编译等效分支冗余优化，实现更高效的专家激活。
