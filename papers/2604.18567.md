# Latent Phase-Shift Rollback: Inference-Time Error Correction Via Residual Stream Monitoring and KV-Cache Steering

## 基本信息
- **arXiv**: [2604.18567](https://arxiv.org/abs/2604.18567)
- **Authors**: Manan Gupta, Dhruv Kumar
- **Conference**: arxiv
- **Year**: 2026
- **Topic**: LLM Inference

## Abstract (English)
Large language models frequently commit unrecoverable reasoning errors mid-generation: once a wrong step is taken, subsequent tokens compound the mistake. Latent Phase-Shift Rollback introduces inference-time error correction via residual stream monitoring and KV-Cache steering, enabling mid-generation error recovery without re-running the entire generation.

## Abstract (中文)
大语言模型在生成过程中经常犯不可恢复的推理错误：一旦走了错误的步骤，后续token会加剧错误。Latent Phase-Shift Rollback通过残差流监控和KV缓存引导引入推理时错误纠正，实现生成中错误恢复而不需要重新运行整个生成过程。
