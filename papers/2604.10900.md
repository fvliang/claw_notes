# CASK: Core-Aware Selective KV Compression for Reasoning Traces

## 基本信息
- **arXiv**: [2604.10900](https://arxiv.org/abs/2604.10900)
- **Authors**: Buseong Kim, Heejun Gwon
- **Conference**: arxiv
- **Year**: 2026
- **Topic**: KV Cache

## Abstract (English)
In large language models performing long-form reasoning, the KV cache grows rapidly with decode length, creating bottlenecks in memory and inference speed. CASK proposes core-aware selective KV compression for reasoning traces, identifying and preserving core reasoning tokens while compressing auxiliary ones.

## Abstract (中文)
在执行长形式推理的大语言模型中，KV缓存随解码长度快速增长，造成内存和推理速度瓶颈。CASK提出推理轨迹的核心感知选择性KV压缩，识别并保留核心推理token同时压缩辅助token。
