# HiveMind: OS-Inspired Scheduling for Concurrent LLM Agent Workloads

## 基本信息
- **arXiv**: [2604.16790](https://arxiv.org/abs/2604.16790)
- **Authors**: Justice Owusu Agyemang, Jerry John Kponyo, Obed Kwasi Somuah, Elliot Amponsah, Godfred Manu Addo Boakye, Kwame Opuni-Boachie Obour Agyekum
- **Conference**: arxiv
- **Year**: 2026
- **Topic**: LLM Serving

## Abstract (English)
When multiple LLM coding agents share a rate-limited API endpoint, they exhibit resource contention patterns analogous to unscheduled OS processes competing for CPU, memory, and I/O. HiveMind proposes OS-inspired scheduling for concurrent LLM agent workloads, reducing failure rates from 27% to near-zero by applying process scheduling concepts to LLM agent orchestration.

## Abstract (中文)
当多个LLM编程代理共享速率受限的API端点时，它们表现出类似于未调度操作系统进程争用CPU、内存和I/O的资源争用模式。HiveMind提出操作系统启发的并发LLM代理工作负载调度，通过将进程调度概念应用于LLM代理编排，将失败率从27%降低到接近零。
