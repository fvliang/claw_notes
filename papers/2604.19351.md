# DASH-KV: Accelerating Long-Context LLM Inference via Asymmetric KV Cache Hashing

## Abstract (English)
The quadratic computational complexity of the standard attention mechanism constitutes a fundamental bottleneck for large language models in long-context scenarios. While KV cache compression methods alleviate memory pressure, they often sacrifice generation quality and fail to address the high overhead of floating-point arithmetic. This paper introduces DASH-KV, a system-aware asymmetric KV cache hashing framework that leverages the inherent anisotropy in token-level KV cache importance to accelerate inference while preserving generation quality. DASH-KV achieves substantial speedups across diverse long-context benchmarks while maintaining high accuracy.

## Abstract (中文)
标准注意力机制的二次计算复杂度是长上下文场景下大语言模型的基本瓶颈。虽然KV缓存压缩方法减轻了内存压力，但往往会牺牲生成质量，并且无法解决浮点运算的高开销问题。本文提出DASH-KV，一种系统感知的非对称KV缓存哈希框架，利用token级KV缓存重要性的固有非对称性来加速推理，同时保持生成质量。DASH-KV在各种长上下文基准上实现了显著加速，同时保持高精度。
