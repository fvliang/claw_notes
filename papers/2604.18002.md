# Neural Garbage Collection: Learning to Forget while Learning to Reason

## 基本信息
- **arXiv**: [2604.18002](https://arxiv.org/abs/2604.18002)
- **Authors**: Michael Y. Li, Jubayer Ibn Hamid, Emily B. Fox
- **Conference**: arxiv
- **Year**: 2026
- **Topic**: KV Cache

## Abstract (English)
Chain-of-thought reasoning has driven striking advances in language model capability, yet every reasoning step grows the KV cache, creating a bottleneck. Neural Garbage Collection learns to forget intermediate reasoning states while preserving important ones, reducing KV cache memory pressure during inference. It applies ideas from garbage collection in programming languages to neural network context management.

## Abstract (中文)
链式思维推理推动了语言模型能力的显著进步，但每个推理步骤都会增长KV缓存，造成瓶颈。神经垃圾回收学会了遗忘中间推理状态同时保留重要状态，减少推理期间的KV缓存内存压力。它将编程语言中的垃圾回收思想应用于神经网络上下文管理。
