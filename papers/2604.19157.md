# SAW-INT4: System-Aware 4-Bit KV-Cache Quantization for Real-World LLM Serving

## Abstract (English)
KV-cache memory is a major bottleneck in real-world LLM serving, where systems must simultaneously support latency-sensitive small-batch requests and high-throughput concurrent workloads. Although many KV-cache compression methods improve offline accuracy or compression ratio, they often violate practical serving constraints such as paged memory layouts, regular memory access, and fused attention kernels. SAW-INT4 proposes system-aware 4-bit KV-cache quantization designed for real-world serving constraints, achieving efficient compression while maintaining serving compatibility.

## Abstract (中文)
KV缓存内存是真实世界LLM服务中的主要瓶颈，系统必须同时支持延迟敏感的小批量请求和高吞吐量的并发工作负载。虽然许多KV缓存压缩方法改善了离线精度或压缩比率，但它们往往违反实际服务约束，如分页内存布局、常规内存访问和融合注意力内核。SAW-INT4提出系统感知的4位KV缓存量化，专为真实世界服务约束设计，实现高效压缩同时保持服务兼容性。
