# SimDiff: Depth Pruning via Similarity and Difference

## 基本信息
- **arXiv**: [2604.19520](https://arxiv.org/abs/2604.19520)
- **Authors**: Yuli Chen, Shuhao Zhang, Fanshen Meng, Bo Cheng, Jiale Han
- **Conference**: arxiv
- **Year**: 2026
- **Topic**: LLM Pruning/Serving

## Abstract (English)
Depth pruning removes entire layers of LLMs to reduce inference cost. SimDiff proposes a novel depth pruning approach via similarity and difference analysis between adjacent layers, enabling more effective layer removal while preserving model quality. It jointly considers both similarity and difference to determine which layers can be safely removed.

## Abstract (中文)
深度剪枝移除LLM的整层以降低推理成本。SimDiff通过相邻层之间的相似性和差异性分析提出一种新颖的深度剪枝方法，实现更有效的层移除同时保持模型质量。它联合考虑相似性和差异性来确定哪些层可以安全移除。
