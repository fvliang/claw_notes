# KV Admission: Learning What to Write for Efficient Long-Context Inference

## 论文信息

- **原文链接**: https://arxiv.org/abs/2512.19887
- **作者**: Yen-Chieh Huang, Pi-Cheng Hsiu, Rui Fang, Ming-Syan Chen
- **年份**: 2025
- **来源**: arxiv

## 摘要 (Abstract)

Long-context LLM inference requires efficient KV cache management. KV Admission proposes a learning-based approach to determine which tokens should be stored in the KV cache, balancing memory usage and model quality.

## 摘要 (中文)

长上下文LLM推理需要高效的KV缓存管理。KV Admission提出了一种基于学习的方法来确定哪些令牌应该存储在KV缓存中，平衡内存使用和模型质量。
