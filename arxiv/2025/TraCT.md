# TraCT: Disaggregated LLM Serving with CXL Shared Memory KV Cache at Rack-Scale

## 论文信息

- **原文链接**: https://arxiv.org/abs/2512.16756
- **作者**: Dongha Yoon, Younghoon Min, Hoshik Kim, Sam H. Noh, Jongryool Kim
- **年份**: 2025
- **来源**: arxiv

## 摘要 (Abstract)

Disaggregated LLM serving with CXL shared memory enables efficient KV cache sharing across GPU nodes. TraCT leverages rack-scale CXL memory to provide high-bandwidth, low-latency access to KV cache, enabling cost-effective scaling of LLM inference.

## 摘要 (中文)

使用CXL共享内存的解耦LLM服务支持跨GPU节点的高效KV缓存共享。TraCT利用机架级CXL内存提供高带宽、低延迟的KV缓存访问，实现具有成本效益的LLM推理扩展。
