# ICaRus: Identical Cache Reuse for Efficient Multi Model Inference

## 论文信息

- **原文链接**: https://arxiv.org/abs/2603.04131

- **年份**: 2026
- **来源**: arxiv

## 摘要 (Abstract)

Multi model inference has recently emerged as a prominent paradigm, particularly in the development of agentic AI systems. However, existing systems lack efficient cache sharing mechanisms across different models, leading to significant memory redundancy. We propose ICaRus, a framework that identifies and reuses identical intermediate activations across different model executions. Our approach achieves significant memory reduction while maintaining inference accuracy.

## 摘要 (中文)

多模型推理最近已成为一种突出的范式，特别是在智能体AI系统的开发中。然而，现有系统缺乏不同模型之间的高效缓存共享机制，导致显著的内存冗余。我们提出了ICaRus，一个在不同模型执行中识别和重用相同中间激活的框架。我们的方法在保持推理精度的同时实现了显著的内存减少。
