# Training-free Dropout Sampling for Semantic Token Acceptance in Speculative Decoding

- **arXiv**: arXiv:2602.0XXXX
- **Authors**: Jeongtae Lee, Minjung Jo, Hyunjoon Jeong, Gunho Park, Sunghyeon Woo, Joonghoon Kim, Se Jung Kwon, Dongsoo Lee
- **Submitted**: 10 February, 2026
- **Topic**: Speculative Decoding

## Abstract (English)

Speculative decoding accelerates large language model inference by proposing tokens with a lightweight draft model and selectively accepting them using a target model. This work introduces DropMatch, a novel approach that matches draft tokens to the predictive distribution of the target model via Monte Carlo dropout applied exclusively to the LM head, enabling sampling-based acceptance decisions.

## 摘要 (中文)

投机解码通过使用轻量级draft模型提出token并使用目标模型有选择地接受它们来加速大型语言模型推理。这项工作介绍了DropMatch，这是一种新方法，通过仅应用于LM头的蒙特卡洛dropout将draft token与目标模型的预测分布进行匹配，从而实现基于采样的接受决策。
