# Quasar: Quantized Self-Speculative Acceleration for Rapid Inference via Memory-Efficient Verification

- **作者**: Guang Huang, Zeyi Wen

- **日期**: 2026年3月1日
- **主题**: Quantization, Self-Speculative Decoding

## 摘要 (Abstract)

### English
We present Quasar, a quantized self-speculative acceleration framework that combines model quantization with self-speculation for efficient LLM inference. Unlike traditional speculative decoding that requires a separate draft model, Quasar uses the quantized target model to generate its own speculative candidates. The key innovation is a memory-efficient verification scheme that enables fast validation of self-generated candidates with minimal overhead. Quasar achieves 2.5x speedup while reducing memory usage by 40%.
