# Fast Heterogeneous Serving: Scalable Mixed-Scale LLM Allocation for SLO-Constrained Inference

## 摘要 (Abstract)

Deploying large language model (LLM) services in heterogeneous GPU clusters presents significant challenges in model allocation and resource management. Different GPU types have varying memory capacities and compute capabilities, making it difficult to serve multiple LLM models while satisfying Service Level Objectives (SLOs). We propose a mixed-scale allocation framework that optimally distributes LLM models across heterogeneous GPUs, balancing SLO compliance with resource efficiency.

## 引言 (Introduction)

Modern LLM serving clusters increasingly comprise heterogeneous GPU hardware, ranging from high-end A100/H100 GPUs to more cost-effective alternatives. Efficiently serving multiple LLM models across such mixed infrastructure requires careful consideration of each model's resource requirements and each GPU's capabilities.
