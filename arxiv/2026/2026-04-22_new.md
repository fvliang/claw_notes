# arxiv 2026 - LLM Serving Papers (新增)

## DASH-KV: Accelerating Long-Context LLM Inference via Asymmetric KV Cache Hashing
- **arXiv**: [2604.19351](https://arxiv.org/abs/2604.19351)
- **Authors**: Jinyu Guo, Zhihan Zhang, Yutong Li, Jiehui Xie, Md. Tamim Iqbal, Dongshen Han, Lik-Hang Lee, Sung-Ho Bae, Jie Zou, Yang Yang, Chaoning Zhang
- **Topic**: KV Cache
- **Abstract (EN)**: The quadratic computational complexity of the standard attention mechanism constitutes a fundamental bottleneck for large language models in long-context scenarios. While KV cache compression methods alleviate memory pressure, they often sacrifice generation quality and fail to address the high overhead of floating-point arithmetic. This paper introduces DASH-KV, a system-aware asymmetric KV cache hashing framework that leverages the inherent anisotropy in token-level KV cache importance to accelerate inference while preserving generation quality.
- **Abstract (CN)**: 标准注意力机制的二次计算复杂度是长上下文场景下大语言模型的基本瓶颈。虽然KV缓存压缩方法减轻了内存压力，但往往会牺牲生成质量，并且无法解决浮点运算的高开销问题。本文提出DASH-KV，一种系统感知的非对称KV缓存哈希框架，利用token级KV缓存重要性的固有非对称性来加速推理，同时保持生成质量。

## SAW-INT4: System-Aware 4-Bit KV-Cache Quantization for Real-World LLM Serving
- **arXiv**: [2604.19157](https://arxiv.org/abs/2604.19157)
- **Authors**: Jinda Jia, Jisen Li, Zhongzhu Zhou, Jung Hwan Heo, Jue Wang, Tri Dao, Shuaiwen Leon Song, Ben Athiwaratkun, Chenfeng Xu, Tianyi Zhang, Xiaoxia Wu
- **Topic**: KV Cache
- **Abstract (EN)**: KV-cache memory is a major bottleneck in real-world LLM serving, where systems must simultaneously support latency-sensitive small-batch requests and high-throughput concurrent workloads. SAW-INT4 proposes system-aware 4-bit KV-cache quantization designed for real-world serving constraints.
- **Abstract (CN)**: KV缓存内存是真实世界LLM服务中的主要瓶颈，系统必须同时支持延迟敏感的小批量请求和高吞吐量的并发工作负载。SAW-INT4提出系统感知的4位KV缓存量化，专为真实世界服务约束设计。

## Neural Garbage Collection: Learning to Forget while Learning to Reason
- **arXiv**: [2604.18002](https://arxiv.org/abs/2604.18002)
- **Authors**: Michael Y. Li, Jubayer Ibn Hamid, Emily B. Fox
- **Topic**: KV Cache
- **Abstract (EN)**: Chain-of-thought reasoning has driven striking advances in language model capability, yet every reasoning step grows the KV cache, creating a bottleneck. Neural Garbage Collection learns to forget intermediate reasoning states while preserving important ones.
- **Abstract (CN)**: 链式思维推理推动了语言模型能力的显著进步，但每个推理步骤都会增长KV缓存，造成瓶颈。神经垃圾回收学会了遗忘中间推理状态同时保留重要状态。
