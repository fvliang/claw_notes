## 介绍

该项目将MLC-LLM模型部署为OpenAI兼容的REST API服务器，支持流式输出、连续批处理和speculative decoding。

## 主要特性

1. OpenAI兼容API
2. 流式输出支持
3. 连续批处理
4. Speculative decoding支持

## 适用场景

- 迁移现有应用
- OpenAI API替代
- 生产部署
