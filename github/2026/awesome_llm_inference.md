# Awesome LLM Inference Papers

## 简介

一个精选的LLM/VLM推理论文列表，包含Flash Attention、Paged Attention、WINT8/4、并行化等技术。

## 项目信息

- **项目名称**: Awesome-LLM-Inference
- **仓库**: [xlite-dev/Awesome-LLM-Inference](https://github.com/xlite-dev/Awesome-LLM-Inference)
- **语言**: Python
- **星标**: 5.1k
- **更新频率**: 活跃 (昨天更新)

## 内容分类

### 量化 (Quantization)

- FP8量化
- INT8/INT4量化
- AWQ, GPTQ, SmoothQuant
- 动态量化

### 注意力机制优化

- Flash Attention
- Paged Attention
- Ring Attention
- Streaming LLMs

### 投机解码 (Speculative Decoding)

- 标准投机解码
- 树形投机解码
- EAGLE, Medusa, Lookahead
- 自投机解码

### 分布式推理

- 张量并行
- 流水线并行
- 专家并行 (MoE)
- 分布式KV缓存

### 系统框架

- vLLM
- Text Generation Inference (TGI)
- LightLLM
- LMDeploy

### 推理引擎

- llama.cpp
- MLC-LLM
- TensorRT-LLM
- PowerInfer

### 相关资源

- 论文链接
- 博客文章

- 教程
