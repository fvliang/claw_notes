# llm-inference-optimization-lab - Benchmark-Driven Serving Platform

## 介绍

一个基准驱动的serving平台，对比Transformers baseline、vLLM、TGI（Text Generation Inference），并可选包含TensorRT-LLM的实验。

## 主要特性

1. 多框架对比（Transformers、vLLM、TGI）
2. 可选TensorRT-LLM支持
3. 量化实验支持
4. 性能基准测试

## 适用场景

- 推理性能对比研究
- 框架选型参考
- 性能优化实验
