# Tiny LLM: Learn LLM Inference Serving on Apple Silicon

## 项目信息

- **项目名称**: tiny-llm
- **GitHub**: https://github.com/skyzh/tiny-llm
- **Stars**: 4k+
- **语言**: Python

## 简介

一个在Apple Silicon上学习LLM推理服务的课程，为系统工程师构建一个精简的vLLM + Qwen。

## 目标

- 教育目的
- 学习LLM推理服务原理
- 在消费级硬件 (Apple Silicon) 上运行

## 特性

- 基于vLLM架构
- 适配Apple Silicon (M系列芯片)
- Qwen模型支持
- 简化实现便于学习

## 适用人群

- 系统工程师
- LLM推理学习者
- 想要了解LLM服务内部原理的开发者
