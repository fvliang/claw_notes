# LightLLM

## 项目信息

- **项目名称**: LightLLM
- **GitHub**: https://github.com/ModelTC/LightLLM
- **Stars**: 4k+
- **语言**: Python
- **最新更新**: 7小时前

## 简介

LightLLM是一个基于Python的LLM (大语言模型) 推理和服务框架，以其轻量级设计、易于扩展性和高吞吐量而闻名。

## 核心特性

### 内存管理
- **Token Attention**: 创新的Token级KV缓存管理
- 非对称内存管理策略

### 多模型支持
- LLaMA系列
- Qwen系列
- MiniMax等

### 高性能
- 多模型批处理
- Prefill-Decode分离
- Tensor并行
- Pipelined并行
- 分页Attention

### 推理优化
- Flash Attention集成
- 量化支持 (INT8, INT4)
- 动态Batch调度

## 架构特点

LightLLM的三大支柱：
1. **Light** - 轻量级实现
2. **Multi-model** - 多模型支持
3. **高性能** - 优化的推理吞吐量

## 部署示例

LightLLM特别适合：

- 高并发服务
- 混合模型部署
