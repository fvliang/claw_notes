# LLMLingua: Prompt Compression for LLM Inference

## 基本信息

- **仓库**: [microsoft/LLMLingua](https://github.com/microsoft/LLMLingua)
- **描述**: [EMNLP'23, ACL'24] To speed up LLMs' inference and enhance LLM's perceive of key information, compress prompt with minimal loss

## 主要特性

- **提示压缩**: 高效压缩LLM提示,减少token数量
- **最小信息损失**: 在压缩过程中保留关键信息
- **推理加速**: 通过压缩提示加速LLM推理
- **多任务支持**: 适用于各种NLP任务

## 原文链接

- GitHub: https://github.com/microsoft/LLMLingua
- Paper: EMNLP 2023, ACL 2024

## 介绍

LLMLingua是微软推出的提示压缩工具,旨在通过压缩提示来加速LLM推理同时保持性能。该方法通过识别和保留提示中的关键信息,使用户能够在不牺牲输出质量的情况下减少token使用量,从而降低推理成本和延迟。
