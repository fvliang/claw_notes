# RouteLLM

## 项目信息

- **项目名称**: RouteLLM
- **GitHub**: https://github.com/lm-sys/RouteLLM
- **Stars**: 4.7k+
- **语言**: Python
- **维护者**: LMSYS

## 简介

一个用于服务和解耦LLM路由器的框架 - 在不牺牲质量的前提下节省LLM成本。

## 核心特性

### 智能路由
- 根据查询复杂度自动选择合适的LLM
- 优化成本与质量的平衡

### 评估
- 内置评估框架
- 路由性能度量

### 支持多种路由策略
- 基于置信度的路由
- 基于性能的路由
- 自适应路由

## 目标

- 降低LLM服务成本
- 保持响应质量
- 提供透明的路由决策
