# Tiny-LLM: Build a Tiny vLLM + Qwen on Apple Silicon

## 项目信息

- **GitHub**: [skyzh/tiny-llm](https://github.com/skyzh/tiny-llm)
- **Stars**: 4k+
- **语言**: Python

## 简介

Tiny-LLM是一个面向系统工程师的LLM推理学习项目，帮助理解LLM推理服务系统的底层实现，并在Apple Silicon上构建一个精简的vLLM + Qwen系统。

## 主要特性

1. **学习导向**
   - 系统级教程
   - 逐步实现指南
   - 适合学习LLM推理原理

2. **Apple Silicon优化**
   - 针对M系列芯片优化
   - Metal加速支持
   - 本地运行无需GPU

3. **精简实现**
   - 最小化依赖
   - 清晰代码结构
   - 易于理解核心概念

## 内容包括

- LLM推理原理讲解
- PagedAttention实现
- 批量调度策略
- 内存管理机制
