# web-llm: High-performance In-browser LLM Inference Engine

## 项目信息

- **GitHub**: [mlc-ai/web-llm](https://github.com/mlc-ai/web-llm)
- **Stars**: 17.6k+
- **语言**: TypeScript
- **组织**: MLC AI

## 简介

web-llm是一个高性能的浏览器内LLM推理引擎，可在WebGPU上运行大语言模型，实现完全的客户端推理。

## 主要特性

1. **浏览器内运行**
   - 完全客户端推理
   - 无需服务器支持
   - 保护用户隐私

2. **WebGPU加速**
   - 利用浏览器WebGPU API
   - GPU级推理性能
   - 跨平台兼容

3. **模型支持**
   - LLaMA系列
   - Phi系列
   - Mistral
   - Qwen
   - 支持多种量化版本

4. **易于集成**
   - NPM包分发
   - TypeScript/JavaScript API
   - 简单易用的接口

## 技术特点

- WASM运行时优化
- 内存管理优化
- 自动批处理
- 流式输出支持

## 使用场景

- 浏览器端AI应用
- 离线可用性要求
- 隐私敏感应用
- 无服务器架构
