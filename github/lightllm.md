# LightLLM: Python-based LLM Inference Serving Framework

## 项目信息

- **GitHub**: [ModelTC/LightLLM](https://github.com/ModelTC/LightLLM)
- **Stars**: 4k+
- **语言**: Python
- **组织**: ModelTC

## 简介

LightLLM是一个基于Python的LLM推理服务框架，以其轻量级设计和易扩展性著称，支持多模型和多卡部署。

## 主要特性

1. **轻量级设计**
   - 简洁的代码架构
   - 易于理解和修改
   - 快速迭代开发

2. **多模型支持**
   - LLaMA系列
   - ChatGLM系列
   - Qwen系列
   - 易于添加新模型

3. **高效服务**
   - Continuous Batching
   - PagedAttention支持
   - Tensor Parallelism

4. **可扩展性**
   - 插件式设计
   - 易于定制
   - 社区活跃

## 架构特点

- 基于Python的异步架构
- 内存管理优化
- 灵活的调度策略

## 性能

- 高吞吐量服务
- 低延迟推理
- 良好的可扩展性

## 使用场景

- 研究原型开发
- 多模型服务
- 生产环境部署
